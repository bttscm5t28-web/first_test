# VLA 2 分钟讲解视频

成品：`vla_2min.mp4`（1920×1080，30fps，120 秒，无音轨，每个画面底部带字幕）

全片用同一个例子贯穿：指令「把红色杯子放到盘子上」+ 同一张桌面场景（机械臂、红杯子、绿方块、蓝盘子）。
颜色固定对应：青色 = 视觉 V，紫色 = 语言 L，橙色 = 动作 A。

| 时间 | 内容 |
|---|---|
| 0–6s | 标题：V · L · A |
| 6–17s | 问题：传统机器人模块化手工设计；大语言模型只会输出文字 |
| 17–29s | 总览：画面 + 指令 → VLA 模型 → 动作，闭环 |
| 29–41s | 第一步 · 看：图像切成 patch → 视觉编码器 → 视觉 token |
| 41–51s | 第二步 · 读：文字 token 与视觉 token 拼接，送入预训练大模型；「杯子」对准画面区域 |
| 51–68s | 第三步 · 做：7 维动作 → 256 格离散化 → 动作 token，模型逐个输出 |
| 68–77s | 另一路线：动作专家（扩散 / 流匹配）直接输出连续动作块 |
| 77–92s | 第四步 · 闭环：看 → 想 → 动，机械臂把杯子放到盘子上 |
| 92–104s | 训练：互联网图文预训练 + 机器人示范数据微调 |
| 104–113s | 泛化：“把能装水的东西拿起来” → 杯子 |
| 113–120s | 总结：看 + 读 → 做 |

## 重新渲染

动画全部在 `index.html` 的 canvas 中按时间 `render(t)` 逐帧绘制（浏览器直接打开可循环预览）。

```bash
NODE_PATH=$(npm root -g) FFMPEG=ffmpeg node render.js            # 输出 vla_2min.mp4（默认 4 个页面并行）
NODE_PATH=$(npm root -g) node render.js --stills 30,60,90        # 只导出几张截图
```

依赖：Playwright（Chromium）、ffmpeg，首次加载需联网获取 Google Fonts。
